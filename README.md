# Learning C++ Journey 🚀

Hey there! This repository is my personal space where I document my progress learning C++ from scratch. I decided to learn C++ because I wanted to understand low-level concepts like pointers, memory allocation, and how Object-Oriented Programming works under the hood.

I am studying using learncpp.com, standard documentation, and by building small console projects.

## Project Structure
- `Day-XX/` - Daily experiments, syntax practice, and exercises.
- `projects/` - Small console applications to apply what I learn.
- `challenges/` - Code challenges and algorithms I solved.
