# C++ Resources & Bookmarks 📚

Here are the sites and books I've been using during my learning journey.

### Websites I check daily:
- [Learn C++ (learncpp.com)](https://www.learncpp.com/) - Honestly the absolute best guide. Very detailed and explains why things work (like why `std::endl` is slow compared to `\n`).
- [cppreference.com](https://en.cppreference.com/) - Great standard library documentation. A bit heavy to read at first, but has the most accurate details for STL methods.
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) - Good practices (especially for pointers and object design).

### Books:
- *A Tour of C++ (3rd Edition)* by Bjarne Stroustrup - Quick overview written by the creator of the language.
- *Effective Modern C++* by Scott Meyers - Helpful for when I started learning C++11/14/17 features (smart pointers, lambda references).

### Other tools:
- [Compiler Explorer (godbolt.org)](https://godbolt.org/) - Amazing for checking assembly output and testing small code snippets.
